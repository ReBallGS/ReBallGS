## O que eu faço

Trabalho com backend Java em sistemas financeiros que exigem disponibilidade, rastreabilidade e conformidade. Desde 2022, na **Dimensa**, evoluo serviços de **Core Banking** e de **PIX** integrados ao **BACEN**: liquidação, disputa, QR Code, Saque/Troco e PIX Automático.

No dia a dia isso significa microsserviços em Spring Boot, processamento assíncrono com Kafka, bases relacionais e MongoDB, e entrega com Docker e Kubernetes. Conduzi a modernização de aplicações de Java 8 para Java 17 e desenvolvi frameworks internos que outras equipes passaram a usar.

O código dos sistemas bancários é proprietário. Os repositórios públicos abaixo mostram como eu estruturo uma API, documento o contrato e cubro o comportamento com teste.

## Projetos públicos

### [Client Registry API](https://github.com/ReBallGS/client-registry)

API REST de cadastro de clientes, feita como amostra de portfólio em **Java 17** e **Spring Boot 3**.

- CRUD com validação de documento e telefone
- Contrato OpenAPI (Swagger UI)
- Migrações com Flyway
- Perfil H2 para subir localmente sem banco externo, e perfil opcional de SQL Server por variável de ambiente
- Testes com JUnit 5 e MockMvc
- Camadas separadas e DTOs desacoplados da entidade JPA

### [Ponto Certo](https://github.com/ReBallGS/ponto-certo-extension)

Extensão do Chrome para calcular o horário de saída a partir da hora de entrada, do almoço e de pausas. Inclui tema claro e escuro, cópia do resultado e um contador de tempo.
